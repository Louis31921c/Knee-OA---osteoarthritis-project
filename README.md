# Knee-OA---osteoarthritis-project
Hi there, in this project, I fine-tune a pretrained ResNet18 to grade knee articular cartilage, aka knee osteoarthritis, from X-ray images, using the Kellgren-Lawrence (KL) grading system — the clinical standard for classifying these symptoms with a scale from 0 to 4 grades, 0 being an intact articulation and 4 being severly damaged
